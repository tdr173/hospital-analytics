\subsection{Reusable Components and Visualisation}

A small library of presentational components in \texttt{frontend/components/generic\_components/} wraps third-party widgets with the project theme: \texttt{StyledTable} (MUI DataGrid used for every list view), the form primitives (\texttt{StyledInput}, \texttt{StyledDropdown}, \texttt{StyledDatePicker}, \texttt{StyledButton} with primary/secondary/add/delete/cancel variants) and the smaller \texttt{Header}, \texttt{Sidebar}, \texttt{FormModal}. Recharts powers the standard cartesian charts on the statistics dashboards; ECharts powers the heatmap and the PCA scatter, where its rendering performance on large patient sets is decisive. The \texttt{/clusters} page exercises every layer described in this chapter: it loads the latest run through the \texttt{clusters} slice, renders one card per cluster styled with the LLM-chosen colour and title, and lets the user drill into the categorical, numerical and PCA sub-views, with the underlying data joined across \texttt{cluster\_meta}, \texttt{cluster} and \texttt{cluster\_patient}.
