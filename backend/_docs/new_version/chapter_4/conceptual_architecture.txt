' ==================================================================
'  INPUT  -  raw data reduced to the dual patient representation
' ==================================================================
rectangle "**Electronic Health Records**\nSynthea synthetic cohort" as ehr <<data>>

rectangle "**Patient population**   P = { p_1, ..., p_n }\n====\n<b>Feature vector</b>   p_i = < x_1, ..., x_m >   //mixed-type//\n<b>Event sequence</b>   S_i = < e_1, ..., e_l >   //temporal//" as dual <<data>>

' ==================================================================
'  STAGE 1 - STRATIFICATION  (operates on the feature vectors)
' ==================================================================
rectangle "**STAGE 1  ·  Stratification**\n== K-Prototypes ==\nPartition P into k homogeneous phenotypes\nand isolate the outlier cohort (label -1)" as s1 <<stage>>

' ==================================================================
'  STAGE 2 - TRAJECTORY EXTRACTION  (operates on the event sequences)
' ==================================================================
rectangle "**STAGE 2  ·  Trajectory Extraction**\n== PrefixSpan ==\nGlobal scope, then once per phenotype\nReveals rare, phenotype-specific pathways\nClosed, ranked and de-duplicated" as s2 <<stage>>

' ==================================================================
'  STAGE 3 - SEMANTIC (INTERPRETATION) STAGE  (on top of both outputs)
' ==================================================================
rectangle "**STAGE 3  ·  Semantic Stage**\n== Large Language Model ==\nReadable phenotype & pathway summaries\nConstrained natural-language query interface" as s3 <<stage>>

' ==================================================================
'  OUTPUT  -  actionable clinical knowledge
' ==================================================================
rectangle "**Clinical Insights & Decision Support**\nManager   ·   Doctor   ·   Patient" as out <<out>>

' ------------------------------------------------------------------
'  FLOWS  -  output of each stage is the input of the next
' ------------------------------------------------------------------
ehr  --> dual

dual --> s1 : feature vectors  p_i
dual --> s2 : event sequences  S_i

s1   --> s2 : phenotypes define\nthe per-cluster scope
s1   --> s3 : phenotypes\n(prototypes)
s2   --> s3 : ranked care\npathways

s3   --> out : plain-language\nknowledge

@enduml
