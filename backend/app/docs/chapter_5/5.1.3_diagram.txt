                                          │
                                          ▼
                              ┌───────────────────────────┐
                              │    build_sequences()       │
                              │                           │
                              │  • prefix events by type  │
                              │    (C:, M:, P:, CP:)      │
                              │  • sort by date, then type│
                              │  • cap at 730 days        │
                              │  • cap at 25 events       │
                              │  • remove consecutive dups│
                              │  • apply blacklist filter │
                              └─────────────┬─────────────┘
                                            │
                                            │  patient sequences
                                            │  e.g. ["C:Hypertension",
                                            │         "M:Lisinopril",

                                            ▼
                              ┌───────────────────────────┐
                              │     mine_patterns()        │
                              │                           │
                              │  • encode vocab           │
                              │  • run PrefixSpan         │
                              │  • score by GML           │
                              │  • type-diversity bonus   │
                              └─────────────┬─────────────┘
                                            │
                                            │  raw candidate patterns
                                            ▼
                              ┌───────────────────────────┐
                              │   filter & rank            │
                              │                           │
                              │  • min support ≥ 1%       │
                              │  • length 3–6 events      │
                              │  • no 3+ same-type runs   │
                              │  • dental cap (max 15)    │
                              │  • Jaccard dedup ≥ 0.80   │
                              │  • keep top 500 by GML    │
                              └─────────────┬─────────────┘
                                            │
                            ┌───────────────┴───────────────┐

Scoping
───────
Global run   : cluster_label = NULL  →  population-wide pathways
Per-cluster  : cluster_label = 0,1,… →  cluster-specific pathways
Outliers     : cluster_label = -1    →  unusual but recurring trajectories

Patient Continuations (clinical decision support)
─────────────────────────────────────────────────
patient recent events  ──►  prefix match against pattern index
                                │
                                ▼
                       matched pattern suffixes
                       = next likely care steps
